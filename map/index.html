LANES / 01

3つのレーン

現在のレーンはヨーク（黄）、ブロードウェイ（青）、グリニッジ（緑）。各レーンでトルーパーを押し上げ、敵の防衛建造物を破壊してパトロンへの道を開きます。レーンの押し引きが、ジップラインで移動できる範囲にも関わります。

ヨーク · 黄ブロードウェイ · 青グリニッジ · 緑
OBJECTIVES / 02

マップ上の目標

  • 中ボス 中央の強敵。撃破するとチーム全体を強化するリジュベネーターを獲得。
  • ソウルアーン 運搬・確保してチームにソウルと強化をもたらす中盤目標。
  • 中立キャンプ レーンの合間に倒して追加ソウルを獲得。強さの異なるキャンプが各所に配置。
    4つの地区 劇場・チャイナタウン・ホーンテッドロット・プラザ。それぞれに独特の地形と拠点がある。
  • テレポーター マップの反対側へ素早く移動し、レーン間のローテーションに利用。
  • 黄金像・箱 破壊してソウルや一時的な強化を得る。
MOVEMENT / 03

移動ルート

レーン間の移動は、ジップラインで前線へ出て、路地やテレポーターで地区を横断するのが基本です。

  1. 拠点からレーンへ ジップラインで自分の担当レーンに合流。
  2. レーンから地区へ ウォーカー周辺の路地・ロープ・風のパッドを使ってジャングルへ。
  3. 別レーンへ移動 テレポーターや中央の通路を使って戦闘や目標に合流。
  4. 帰還・立て直し ジップラインで拠点へ戻り、回復・購入後に前線へ復帰。
  • ジップライン 拠点から各レーンへ移動。レーンの進行状況に応じて利用可能範囲が変わります。
  • ロープ 中層や屋上へ上り、立体的に移動。
  • 風のパッド 大きく跳び、戦闘への参加や離脱に使います。
  • レーン間の路地 敵の視界を避けたガンクやキャンプ巡回に利用。
MATCH FLOW / 04

試合の流れ

  1. レーンでソウルを集め、序盤のアイテムを購入。
  2. 敵のガーディアンとウォーカーを破壊し、マップを広げる。
  3. 中盤は中立キャンプやソウルアーンでチームの優位を築く。
  4. 中ボスやシュラインを攻略し、敵パトロンを破壊する。
