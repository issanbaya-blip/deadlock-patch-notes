# Deadlock 情報ベース

Deadlockのマップ・キャラ・アイテム・アップデートを日本語で確認できるファンサイトです。

## ページ

- `/` 情報カテゴリの大目次
- `/map/` マップ地形、レーン、目標物、移動手段
- `/heroes/` ヒーロー44人の検索、特徴、能力、ステータス、掲載中の変更
- `/items/` 武器・生命力・スピリットのアイテム検索、価格、ティア、アイコン、効果
- `/updates/` ヒーロー・一般・アイテム・ストリートブロールのアップデート情報とSteam最新投稿の確認

ヒーローとアイテム情報はゲームデータの公開スナップショットをもとに表示しています。マップ地形画像はDEADLOCK-JP DBの公開素材です。非公式のファンサイトで、Valveとは関係ありません。

## ローカルで見る

`index.html` をブラウザーで開くと目次を表示します。最新ニュース取得機能はCloudflare Pages Functionsが必要です。

## 公開

Cloudflare Pagesで公開。`functions/api/latest.js` がSteam公式ニュースを取得します。
