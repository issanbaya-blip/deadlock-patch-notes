# Deadlock アップデートノート

Deadlockのアップデート情報を日本語で読みやすくまとめる、静的サイトです。

## 表示

- ヒーロー別の変更、変更のないヒーローのグレーアウト
- アイテム画像付きの調整一覧
- Steam公式ニュースの最新投稿を確認するボタン
- キーワード検索とスマートフォン対応

## ローカルで見る

静的ファイルは `index.html` をブラウザーで開いて表示できます。最新ニュースの取得機能はCloudflare Pages Functionsが必要です。

## 公開

Cloudflare Pagesで公開しています。`functions/api/latest.js` がSteamの公式ニュースから最新のDeadlock投稿を取得します。新しい公式投稿は原文で表示され、現在の日本語整理版と区別されます。
